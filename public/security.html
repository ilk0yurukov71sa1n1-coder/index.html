Security

How we protect this site and your keys

This website

  • HTTPS everywhere with HSTS preload.
  • A strict Content Security Policy: only our own scripts run, and the site cannot be framed.
  • Forms accept same-origin JSON only, are rate limited per IP and include bot traps.
  • No secrets ship to the browser. Every build is scanned for leaked keys before it can deploy.
  • Database tables are locked with row-level security. Only our server can read them.

The gateway

  • Provider keys are encrypted at rest and never returned by the API.
  • Your app holds a scoped Rollcfluence key with its own spend cap, rate limit and allowed models.
  • Keys can be rotated or revoked instantly.

Report a vulnerability

Found something? Email rollcfluence@gmail.com with the subject "Security report". Please give us a chance to fix it before sharing it publicly. We reply to every report.
